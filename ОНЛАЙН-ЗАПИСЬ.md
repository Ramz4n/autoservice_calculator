# Онлайн-запись с сайта — что нужно знать в программе

Полная инструкция (сайт, панель, безопасность): `Desktop\autoservice_site\ИНСТРУКЦИЯ.md`

## Что делает программа
Модуль `web_sync.py` раз в минуту (и при открытии окна «Записать клиента») связывается с сайтом:
- отправляет настройки слотов и предстоящие записи (только при изменениях);
- забирает записи с сайта (`🌐 Сайт: …`) и из панели на телефоне (`📱 С телефона: …`) — статус «ожидание»;
- выполняет отмены из панели;
- о новых записях показывает окошко «Новые записи с сайта» в правом нижнем углу.
- отправляет список марок и моделей авто, когда он изменился. Клиент на сайте может выбрать машину
  только из этого списка: добавили марку или модель в программе — через минуту её можно выбрать на сайте.
  Если машины клиента нет в списке, сайт просит позвонить.

Госномер на сайте можно вписать любой страны (буквы, цифры, дефис). Российский номер, набранный латиницей,
сохраняется кириллицей (A123BC77 → А123ВС77), остальные — как написаны.

База MariaDB при этом наружу не открывается — программа сама ходит на сайт по HTTPS.

## Настройки
**`config/.env`** — включение синхронизации:
```
WEB_SYNC_URL=https://your-site-domain
WEB_SYNC_KEY=<секретный ключ>
```
Нет этих строк (или они с `#`) — синхронизация выключена, программа работает как раньше.

**`config/settings.json`** — общие правила записи для программы и сайта:
| Ключ | Что это |
|---|---|
| `working_hours_start`, `working_hours_end` | часы записи (включительно), например 10 и 20 |
| `slot_duration_minutes` | шаг записи, например 120 → 10:00, 12:00 … 20:00 |
| `max_cars_per_slot` | сколько машин можно записать на одно время (сейчас 3) |
| `max_bookings_per_user` | сколько ожидающих онлайн-записей на один телефон |

> ⚠ Синхронизацию включать **только на компьютере автосервиса**. На тестовом/рабочем ПК разработчика
> закомментировать строки `WEB_SYNC_…`, иначе тестовые записи займут время на настоящем сайте.

## После изменения кода
Закрыть программу → `build.bat` → дождаться `=== Done ===`.
Если программа открыта во время сборки, сборка не получится и останется старая версия
(признак: нет файла `logs/web_sync.log` после запуска).

## Если что-то не так
Смотрите `logs/web_sync.log` рядом с программой — туда пишется, есть ли связь с сайтом, и текст ошибки.

## Что изменено в программе для онлайн-записи
- `web_sync.py` — новый модуль синхронизации;
- `autoservice_calculator.py` — запуск синхронизации, окошко о новых записях, часы записи из настроек;
- `database.py` — `max_cars_per_slot` (несколько машин на одно время);
- `db_schema.py` — колонка `bookings.web_id` (номер заявки на сайте, защита от дублей);
- `config/locales/*.json` — тексты окошка;
- `db_schema.py` — колонка `clients.tg_verified` для Telegram-бота (см. `tgbot/ИНСТРУКЦИЯ-БОТ.md`);
- копия кода до изменений: `Backup/code_before_web_sync_2026-10-22_010057.zip`.
