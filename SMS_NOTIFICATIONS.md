# SMS-уведомления клиентам («авто готово») — настройка и использование

Когда заказ отмечается как **«Выполнено»**, программа теперь автоматически:
- шлёт уведомление в Telegram (если у клиента есть `telegram_user_id`);
- шлёт SMS на номер телефона клиента из карточки (`clients.phone`).

Оба канала независимы: если клиент не привязан к Telegram-боту — уйдёт только SMS, и наоборот.

---

## 1. Зарегистрироваться в SMSC.ru

1. Перейти на https://smsc.ru и создать аккаунт.
2. Пополнить баланс (SMS в РФ — обычно от ~2-4 ₽ за сообщение).
3. Зайти в личный кабинет → раздел **API** (или «Настройки» → «Программистам»).

## 2. Получить ключ доступа

Есть два варианта, нужен один из них:

**Вариант А — API-ключ (рекомендуется)**
В личном кабинете SMSC.ru: «Настройки» → «API» → сгенерировать **API-key**.
Он безопаснее пароля — его можно перевыпустить, не меняя пароль от аккаунта.

**Вариант Б — логин и пароль**
Используются логин и пароль от личного кабинета smsc.ru напрямую.

## 3. Заполнить config/.env

Открыть `config/.env` в корне проекта, там уже есть заготовка:

```
# SMSC.ru - заполните SMSC_API_KEY (рекомендуется) или логин+пароль от личного кабинета smsc.ru
SMSC_API_KEY=
SMSC_LOGIN=
SMSC_PASSWORD=
SMSC_SENDER=
```

Заполнить **один** из вариантов:

```
SMSC_API_KEY=ваш_api_key
```
или
```
SMSC_LOGIN=ваш_логин
SMSC_PASSWORD=ваш_пароль
```

`SMSC_SENDER` — необязательное поле. Если хотите, чтобы вместо номера в SMS клиент видел имя отправителя (например `AlexAuto`), нужно:
1. Заказать именной префикс в личном кабинете SMSC (раздел «Имя отправителя») — там же его согласовывают.
2. Вписать точно это же имя в `SMSC_SENDER`.

Если поле пустое — SMS придёт с обычного короткого номера SMSC.

## 4. Проверить, что всё работает

1. Убедиться, что в карточке клиента (`clients.phone`) указан телефон в формате `+7...` или `8...`.
2. Открыть программу → вкладка «Записи» → выбрать запись → **«Отметить выполненной»**.
3. Если SMS ушло — появится сообщение об успешной отправке уведомления.
4. Если SMS не пришло — смотреть консоль/лог программы, там будет строка вида:
   ```
   Ошибка отправки SMS (+79991234567): <текст ошибки от SMSC> (код ...)
   ```
   Частые причины:
   - `SMSC_API_KEY`/`SMSC_LOGIN`+`SMSC_PASSWORD` не заполнены — тогда в консоли будет
     `SMS не отправлено: не заданы SMSC_API_KEY или SMSC_LOGIN/SMSC_PASSWORD в config/.env`.
   - На балансе SMSC закончились деньги.
   - Неверный формат номера в `clients.phone`.

## 5. Что уходит в SMS

Короткий текст без HTML, например:

```
Ваш автомобиль Toyota Camry (А123ВС777) готов, ждём вас! Заказ-наряд № 45. Итого: 8500 ₽. AlexAuto, г.Щёлково, ул.Беляева, д.6Б, +7-960-546-62-81
```

Если к записи не привязан наряд (работа), номер заказа и сумма просто не включаются в текст.

## 6. Где это в коде

| Файл | Назначение |
|------|------------|
| `sms_notifications.py` | функция `send_sms_notification(phone, message)` — отправка через HTTP API SMSC.ru |
| `autoservice_calculator.py` → `mark_booking_completed()` | формирует текст и вызывает отправку при отметке заказа выполненным |
| `config/.env` | хранит `SMSC_API_KEY` / `SMSC_LOGIN` / `SMSC_PASSWORD` / `SMSC_SENDER` |

Чтобы сменить SMS-провайдера в будущем — достаточно переписать только `sms_notifications.py`, вызов `send_sms_notification(phone, text)` в `autoservice_calculator.py` менять не придётся.
