# Автотесты

Тесты запускают настоящую программу (`AutoServiceApp`) на **тестовой** базе, заполняют формы и нажимают
кнопки как администратор, а результат проверяют запросами к базе.

## Запуск

```
python tests/run_all.py            # все тесты
python tests/run_all.py edit hint  # только тесты, в имени которых есть edit или hint
```

Коротко итог — в консоли, подробный лог — `tests/last_run.txt`. Код выхода 0 — всё прошло.
Тест длится около 2 минут; на экране мелькает окно программы — это нормально.

## Безопасность

- Тесты **пишут в базу**, поэтому запускаются только если в `config/.env` есть `ALEXAN_TEST_DB=1`.
  Флаг стоит только на компьютере разработчика (`.env` не попадает ни в git, ни в релиз).
  **На базе клиента этот флаг не ставить.**
- Перед тестами — резервная копия в `Backup`.
- После тестов удаляется всё, что они создали (строки с id больше, чем были до запуска), и должности
  возвращаются как были. Это тоже проверяется («после уборки база как до тестов»).
- Тестовые данные — на свои госномера и телефоны (`Т1xxТТ799`, `Т2xxТТ799`, `+79000000xxx`), имена «Тест …».
  Если такие уже есть в базе, набор не запускается.

## Файлы

| Файл | Что внутри |
|---|---|
| `harness.py` | Обвязка: запуск программы, автоответы на окна-вопросы, заполнение форм (`booking_form`, `works_form`, `warehouse_form`, `edit_form`), `check`, `expect_rejected`, уборка |
| `test_positive.py` | Позитивные проверки: сохраняется то, что нужно |
| `test_negative.py` | Негативные: неверный ввод → предупреждение и **ни одной** записи в базе (`expect_rejected`) |
| `run_all.py` | Запуск наборов, фильтр по имени, итог |

## Что покрыто

| Область | Позитивные | Негативные |
|---|---|---|
| «Записать клиента» | новая машина (номер латиницей → кириллица), повтор на то же время, Х555ХХ77 → Х555ХХ777 | пустой госномер, без марки/модели/телефона/имени, неполный телефон, госномер с ошибкой (нет первой буквы, буква «Г», не по образцу) |
| «Добавить работу» | работа по записи, новая машина без записи, открытие записи «в работе» по госномеру | без мастера/работ/марки/модели/госномера, госномер с ошибкой, цена 0/буквами/минус, дубль работы, пустое название |
| Склад | запчасть для найденной и для новой машины | без названия, количество/цена буквами, без марки/модели, неполный телефон, госномер с ошибкой |
| Поиск по госномеру | подсказка Х555ХХ77 без подстановки («Добавить работу», склад) | — |
| «Изменить данные» | смена госномера (латиницей), модели, имени — та же машина и клиент | пустые госномер/марка/модель, неполный телефон, чужой госномер, чужой VIN, госномер с ошибкой, чужой телефон |
| «Записи» → Удалить | запись с работой: работа удаляется, запчасть отвязывается | — |
| Сотрудники и должности | должность «с машинами», сотрудник в «Добавить работу», выключение, удаление | пустое/повторное название, без ФИО, повторное ФИО, переименование в существующее, последнюю «с машинами» не выключить и не удалить |

Не покрыто: «Отчёты» (выплаты, премии), «Финансы», «Статистика», окна выбора нового владельца,
PDF, ввод с реальной клавиатуры (ввод имитируется).

## Как добавить проверку

1. Позитивная — функция `test_…(h)` в `test_positive.py`, в конце добавить её в `TESTS`.
   Заполнить форму через `h.*_form(...)`, проверить базу через `h.q(...)` и `h.check(...)`.
2. Негативная — в `test_negative.py`: `h.expect_rejected("что проверяем", действие, "часть текста предупреждения")`.
   Если программа задаёт вопрос «Да/Нет» — `answers=[False]` (ответить «Нет»).
3. Новые госномера / телефоны — в `PLATES` / `PHONES` набора (проверяются на занятость перед запуском).
4. Обновить таблицу «Что покрыто» выше.
