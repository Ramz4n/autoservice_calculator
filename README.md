# AutoService — программа для автосервиса

Программа для Windows: запись клиентов, наряды (работы и запчасти), склад запчастей,
сотрудники, отчёты и статистика, лист-наряд в PDF. Данные хранятся в MariaDB.

Текущая версия — в файле `VERSION` (поднимает `package_release.bat` при каждой сборке релиза),
история изменений — в [`CHANGELOG.md`](CHANGELOG.md).

## Структура проекта

```
.
├── autoservice_calculator.py   # программа (интерфейс и логика)
├── database.py                 # работа с базой данных
├── db_schema.py                # таблицы и обновления структуры базы (MIGRATIONS)
├── db_config.py                # подключение к базе (из config/.env)
├── backup.py                   # резервное копирование и восстановление
├── web_sync.py                 # онлайн-запись с сайта (см. ОНЛАЙН-ЗАПИСЬ.md)
├── i18n.py                     # переводы интерфейса
├── config/
│   ├── .env                    # настройки подключения к базе (не в git)
│   ├── settings.json           # настройки программы
│   └── locales/                # переводы: ru, en, ka, hy, sr
├── tgbot/                      # Telegram-бот
├── autoservice_calculator.spec # сборка .exe (PyInstaller)
├── build.bat                   # сборка .exe
├── package_release.bat         # релиз: поднимает версию, собирает, пакует в release\*.zip
└── docs/                       # документация
```

## Запуск

Требования: Python 3.11+, MariaDB 10.6+.

1. Настройки подключения к базе — в `config/.env`:
   ```
   DB_HOST=localhost
   DB_PORT=3306
   DB_USER=...
   DB_PASSWORD=...
   DB_NAME=...
   ```
2. Установить зависимости и запустить:
   ```bash
   pip install -r requirements.txt
   python autoservice_calculator.py
   ```

База и таблицы создаются при первом запуске сами.

## Сборка .exe

```bash
build.bat
```
Готовая программа — в `dist\autoservice_calculator`. Скрипт сохраняет и возвращает
файлы, которые лежат рядом с .exe (`.env`, `Backup`).

## Обновление базы при запуске

При каждом запуске программа сверяет структуру базы со списком `MIGRATIONS` в `db_schema.py`
и дополняет её. Обновления **только добавляют поля и чистят данные — ничего не удаляют**.

Перед изменением структуры уже работающей базы программа сама делает полную копию
в папку `Backup` рядом с программой — её видно и можно восстановить во вкладке
«Резервное копирование». Если копию сделать не удалось, программа спросит, продолжать ли.

Перед обновлением программы в автосервисе всё равно сделайте копию вручную:
«Резервное копирование» → «Создать копию».

## Основные таблицы базы

- **clients** — клиенты (имя, телефон, Telegram)
- **client_cars** — машины (госномер уникален; владелец — `client_id`)
- **bookings** — записи (дата, время, статус)
- **works** — наряды (работы, сумма, мастер, пробег; `client_id` — клиент наряда)
- **parts** — запчасти в нарядах
- **warehouse_parts** — склад запчастей (статус: заказана / на складе / установлена / выдано)
- **workers** — сотрудники
